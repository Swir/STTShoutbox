# STTShoutbox 2.5.1

Red × moderation controls and a cleaner public chat.

- Administrators, super moderators and assigned forum moderators can remove public messages with an accessible red × button.
- Removed and previously withdrawn public messages leave no empty row or withdrawal notice.
- Removals reach other open chats, including loaded older history; delayed responses cannot restore removed messages.
- Regular members can still withdraw only their own messages. Private conversation permissions remain unchanged.

Upload all files from `Upload` to your MyBB root, replacing the old plugin files, and refresh the forum. For an upgrade from 2.5.0 there is no schema migration or reactivation step. Do not uninstall. Back up your files and database before upgrading.

The delete control removes messages from the chat view using the existing withdrawal records. It does not erase database records or backups.

Polski: czerwony × dla administracji i moderatorów usuwa wpis z widoku wszystkim, bez komunikatu „Wiadomość została wycofana”. Aktualizacja z 2.5.0 wymaga podmiany plików i odświeżenia strony; nie odinstalowuj wtyczki.
